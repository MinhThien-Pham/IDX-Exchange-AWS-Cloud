# Week 1 — Cloud Fundamentals & Account Setup

The AWS root user has complete access to the AWS account and should only be used for tasks that require root privileges. I enabled MFA on the root user to add an additional layer of protection. For normal administrative work, I use a separate IAM user instead of signing in as root. An IAM user is an identity inside an AWS account that can be assigned permissions through IAM policies. Under the AWS Shared Responsibility Model, AWS is responsible for security of the cloud, including the physical infrastructure and underlying AWS services. Customers are responsible for security in the cloud, including IAM permissions, data, applications, and configuration choices. I also configured AWS budgets and billing monitoring to track cloud spending and catch unexpected charges.
