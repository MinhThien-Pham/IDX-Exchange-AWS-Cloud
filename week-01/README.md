# Week 1 — Cloud Fundamentals & Account Setup

The AWS root user has complete access to the AWS account and should only be used for tasks that require root privileges. I will use a separate IAM user for normal administrative work instead of using the root user every day. An IAM user is an identity inside an AWS account that can be assigned permissions for specific tasks. Under the AWS Shared Responsibility Model, AWS is responsible for security of the cloud, including the physical infrastructure and underlying AWS services. Customers are responsible for security in the cloud, including IAM permissions, data, applications, and configuration choices. The exact division of responsibility depends on which AWS service is being used. I will enable MFA and configure cost alerts once my AWS account access is restored.
